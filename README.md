# Aura Box

Eén bestand: `index.html` (HTML, CSS en JavaScript zitten erin, logo is inline SVG).
Lettertypes (Cormorant, Poppins, Amiri, Cairo) komen van Google Fonts.

## Op GitHub Pages zetten
1. Maak een repository en upload deze bestanden naar de hoofdmap.
2. Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)`.
3. Na een minuut staat de site op `https://<gebruiker>.github.io/<repo>/`.

## Talen
FR (standaard), AR (RTL) en EN. Teksten staan in het object `T` onderaan `index.html`.
